ホームプライバシーポリシー利用規約

プライバシーポリシー

最終更新日：2026年11月5日

1. 対象

このプライバシーポリシーは、行動心理ちゃんねるの運営者が使うツール「koudou-shinri-uploader」（以下「本ツール」）に適用されます。

2. 本ツールが使うGoogleのデータ

本ツールはGoogleのOAuthで、次の権限だけを使います。

  • YouTubeへの動画のアップロードと、アップロードした動画の情報（タイトル・説明・タグ・公開設定）の編集
  • 自分のチャンネルと動画の公開情報（登録者数・再生数・公開予定日時など）の読み取り
  • Googleフォトへの動画の追加
  • Googleカレンダーへの公開予定・作業予定の追加と更新（本ツールが作った予定だけ）

運営者本人のアカウントだけで使い、ほかの人のアカウントやデータにはアクセスしません。

3. データの保存

認証情報（アクセストークン）と取得した数字は運営者のPCの中にだけ保存します。YouTubeやGoogleから取得したデータを、外部のサーバーに保存したり送ったりしません。

4. 第三者への提供

取得したデータを第三者に提供・販売することはありません。

5. YouTube API Services の利用

本ツールは YouTube API Services を利用しています。YouTube利用規約とGoogleプライバシーポリシーもあわせてご確認ください。

6. 許可の取り消し

本ツールに与えた権限は、Googleアカウントのセキュリティ設定からいつでも取り消せます。

English summary

koudou-shinri-uploader is used only by the channel owner with the owner's own Google accounts. It uses the YouTube Data API (upload and edit the owner's own videos, read the owner's own channel and video statistics), the Google Photos Library API (add videos) and the Google Calendar API (add and update only the events it created). OAuth tokens and retrieved data are stored only on the owner's computer. No data is shared with, sold to, or stored by any third party. This tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at https://security.google.com/settings/security/permissions.
